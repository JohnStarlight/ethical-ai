# Reflection

Until recently, I have only used AIs for research mostly. I haven't been using it for coding until I entered the piscine. There, initially I just dropped the whole exercise for it to see what it needed to be done and just do it.
That wasn't very satisfying though so I started asking directions and advice in order to better understand how it works rather than just offering a working program that I can't understand its ins and outs.
I have tried in multiple occasions making something on my own. Some tries have been successful while others needed fixing and those that did, I tried to make the LLM tell me what to do in order to memorize and learn it and be able to do it on my own if needed instead of just letting it fix it. Besides trying to understand how something works and learn, I've always tried to make myself independent of any LLMs because... well to be honestt, I'm a bit proud like that. I want to be able to make things on my own rather than depend on an AI. In the case it was taken away from me, I would like to remain productive, not lost!

My current pattern is a bit of both ways. I'm using it to generate answers, read and try to understand them with or without the LLM's help. If I'm having a task to complete which includes unknown programming language or unknown aspects of one I'm currently learning, I will ask the LLM to produce an answer first and then ask it to explain whatever I don't fully grasp in order to be able to read and understand the code. That's in order to get a starting glimpse of the language's syntax and start going from there.

To be completely honest, I believe I'm where I need to be in terms of having the right mindset and attitude towards empowered learning and empowered producing. At least that's what I think for the time being. I'm always reevaluating myself as I move forward.
