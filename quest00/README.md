# Summary

In a TL/DR format: AI is amazing if I use it to empower me, not replace me.

What this means in greater detail is that having an AI do all my tasks and work, actually does nothing good for me.
Yes, it will give me a boost on completed projects but that just proves that it's the tool that's indispensable, not me.
It's the tool that's working so it's the tool that's staying, because others can have it make the same things as well.
And not to miss the most important detail in this: these tools are not mine! I can use them for free right now or for a small fee but that is subject to change.

In order to avoid being irrelevant, I need to be the one doing the important work and in order to be able to do that I need to have the knowledge to do so.
So let me do the core work, the designing and the task asignment and then I can have an AI do the heavy lifting, the menial tasks.
I can use it to optimize, to debug but to the extend I can understand.
Which brings me to the next point: I can't have it make code I don't understand.
I have to make it keep me in the loop, inform me, teach me, so I can understand how things work and be able to make them myself without any help should I need or want to.

On the learning front, in order to actually learn how things work, I need to be able to understand what I have in front of me.
Wether it's a program in golang or an algorithm, I have to be able to understand what it does and, in the case of a programming laguage, how it does it.
I need to use the AI to speed up my learning pace, not to provide me with answers I don't fully grasp. That's the trap right there.
Hunting for grades and good performance metrics while learning is fine as long as it's me who's doing the work. Otherwise the grades belong to the AI, so it should be considered cheating and unethical if it's me that's being graded using its work. Not the same case when we are talking about a project where I dictate what I want and it does it but again, I do have to be able to understand it to the point I can explain it to another person in detail. In essence I need to be able to reproduce it and if I can, that's proof I own the knowledge.

Have the AI explain some concepts I don't understand instead of have it use them in order to optimize a project. If I understand them and can use them properly myself, then it's perfectly fine to let it use them but not before that.
Have the AI give me guidelines instead of code if I'm stuck at the logic level in a task where I'm confident I have the required knowledge to solve but lack the vision of the solution. This way I'm learning different approaches to problem solving and examine the problem from a different angle.
Have the AI do whatever in these terms but always consider the possibility it's wrong. And this brings me to a rhetorical question that's distilled from all the previous things I've written: How would I know it's wrong if I don't understand what it's doing?
That pretty much sums everything up.
